สรุปว่านักเรียนและครู/แอดมิน กดอะไรแล้วระบบทำอะไร
อ้างอิงจากโค้ดจริงของเว็บแอป (เวอร์ชันปัจจุบัน)

ฝั่งนักเรียน + ฝั่งครู/แอดมิน

สารบัญ

  1. ภาพรวมระบบ
  2. Flow หลักแบบสั้น (End-to-End)
  3. ฝั่งนักเรียน — เมนูและผลของการกด
  4. ฝั่งครู/แอดมิน — เมนูและผลของการกด
  5. การหักชั่วโมง / แจ้งเตือนอัตโนมัติ
  6. ตาราง Route สรุป

1) ภาพรวมระบบ

หลักการสำคัญ
  • เว็บเป็นช่องทางหลัก · LINE OA เป็นช่องทางแจ้งเตือนเสริม
  • จองแล้วยังไม่หักชั่วโมง — หักเมื่อนักเรียนลงชื่อหลังเรียน (หรือครูบันทึก No-show)
  • ซื้อแพ็กเกจแล้ว ยังไม่ได้ชั่วโมงทันที — ต้องโอน → แนบสลิป → ครูยืนยัน
  • แพ็กเกจอายุ 6 เดือน นับจากวันที่ยืนยันรับเงิน

2) Flow หลักแบบสั้น (End-to-End)

สมัครสมาชิก → ซื้อแพ็กเกจ / รับลิงก์ชำระเงิน → โอน PromptPay + แนบสลิป → ครูยืนยันรับเงิน (ได้ชั่วโมง) → จองวัน–เวลาเรียน → ระบบเตือนก่อนเรียน ~1 วัน → นักเรียนยืนยันมาเรียน → เข้าเรียน → ครูบันทึกคลาส + การบ้าน → นักเรียนลงชื่อหลังเรียน (หักชั่วโมง) → ดูประวัติ / ใบเสร็จ

3) ฝั่งนักเรียน

3.1 เมนูที่นักเรียนใช้

เมนูหน้า (Route)ใช้ทำอะไร
หน้าแรก/appดูนัดถัดไป · ยืนยัน/เลื่อน/ยกเลิก · ชม.คงเหลือ
ซื้อแพ็กเกจ/app/packagesเลือกแพ็ก · ใส่วอเชอร์ · เริ่มชำระ
ชำระเงิน/app/pay/:refดู QR · แนบสลิป · แจ้งโอน
จองเวลาเรียน/app/bookingเลือกวัน/เวลา/โหมดเรียน · ยืนยันจอง
ประวัติการเรียน/app/historyดูบันทึกจากครู
การบ้าน / ลงชื่อ/app/homeworkลงลายเซ็นหลังเรียน · ส่งเสียงการบ้าน
ใบเสร็จ / การซื้อ/app/receiptsดูประวัติการชำระ
โปรไฟล์/app/profileแก้ข้อมูล · เชื่อม LINE · เชื่อม Google Calendar

3.2 สมัคร / เข้าสู่ระบบ

กดอะไรผลในระบบ
สมัครด้วยอีเมล+รหัสผ่านสร้างบัญชีนักเรียน · แจ้งต้อนรับ · พาไปหน้าซื้อแพ็กเกจ
สมัคร / เข้าสู่ระบบด้วย LINEOAuth LINE · ผูกบัญชี · เข้าหน้านักเรียน
เข้าสู่ระบบอีเมล/เบอร์ได้ session · ไป /app

3.3 ซื้อแพ็กเกจ + ชำระเงิน

กดอะไรผลในระบบ
เลือกแพ็กเกจ → ชำระเลยสร้างออเดอร์สถานะ รอโอน · ยังไม่เติมชั่วโมง · แจ้งเตือนในแอป
ใช้โค้ดวอเชอร์ตรวจโค้ด · ลดราคาก่อนสร้างออเดอร์
ชำระจากลิงก์/ผ่อนที่ครูสร้างสร้างออเดอร์จากลิงก์นั้น · ไปหน้าชำระ
แนบสลิป + แจ้งโอนแล้วสถานะ รอครูยืนยัน · แจ้งครูทุกคนที่กระดิ่ง/LINE
ครูยืนยันรับเงิน (ฝั่งครู)สถานะสำเร็จ · เติมชั่วโมง · แพ็กอายุ 6 เดือน · แจ้งนักเรียน
ครูปฏิเสธสลิปออเดอร์ยกเลิก · แจ้งนักเรียน · ไม่ได้ชั่วโมง

3.4 จองเรียน / ยืนยัน / เลื่อน / ยกเลิก

กดอะไรผลในระบบหักชม.?
จองวัน–เวลา + ยืนยันการจองสร้างนัดสถานะ รอคอนเฟิร์ม · ล็อกสล็อต · แจ้งครู · sync Google Calendar (ถ้าเชื่อม)ไม่
ยืนยันการมาเรียน (หน้าแรก)นัดเป็น ยืนยันแล้ว · แจ้งครูไม่
ปฏิเสธนัด (ยังไม่ยืนยัน)ยกเลิกนัด · สล็อตว่างไม่
ขอเลื่อนนัดสร้างคำขอเลื่อน · รอครูอนุมัติ ≤24 ชม.ไม่
ยกเลิกนัด (≥24 ชม.ก่อนเรียน)ยกเลิก · สล็อตว่าง · แจ้งครูไม่
ปุ่ม Google Calendar บนหน้าแรกเปิดลิงก์เพิ่มลงปฏิทินด้วยมือ—
กติกาสำคัญตอนจอง
  • ต้องมีชั่วโมงคงเหลือก่อนจองได้
  • ถ้าไม่ยืนยันภายในกำหนด ระบบยกเลิกนัดอัตโนมัติ (สล็อตว่าง)
  • ก่อนเรียนประมาณ 1 วัน ระบบส่งแจ้งเตือนในแอป + LINE (ถ้าผูก) + เตือนครู

3.5 หลังเรียน — ลงชื่อ / การบ้าน

กดอะไรผลในระบบ
ครูบันทึกคลาส “มาเรียน”สร้างบันทึกคลาส · แจ้งนักเรียนให้ลงชื่อ · มีการบ้านถ้าครูใส่โน้ต/เสียง
นักเรียนลงลายเซ็นหลังเรียนหักชั่วโมง ตามระยะเวลาคลาส (ปกติ 1 ชม.)
ครูบันทึก No-showหักชั่วโมงทันที · แจ้งนักเรียน
อัปโหลด/อัดเสียงการบ้านบันทึกไฟล์เสียง · ครูฟังได้ในปฏิทิน

3.6 โปรไฟล์นักเรียน

กดอะไรผลในระบบ
แก้ไขข้อมูลส่วนตัวอัปเดตโปรไฟล์
เชื่อมต่อ LINEผูกบัญชีเพื่อรับแจ้งเตือน Push
เชื่อมต่อ Google Calendarsync นัดเรียน + เตือนล่วงหน้า 1 วันในปฏิทิน Google

4) ฝั่งครู / แอดมิน

4.1 เมนูที่ครูใช้

เมนูหน้า (Route)ใช้ทำอะไร
วันนี้/teacherสรุปงานวันนี้ · KPI · ทางลัด
ตารางสอน/teacher/calendarเปิด/ปิดสล็อต · จองให้นักเรียน · บันทึกคลาส
คำขอเลื่อนนัด/teacher/requestsอนุมัติ/ปฏิเสธคำขอเลื่อน
ข้อมูลนักเรียน/teacher/studentsดูรายชื่อ · โปรไฟล์ · สร้างคอร์ส/offer
รายงาน / ยอดขาย/teacher/salesดูยอดขาย · Export CSV
ยืนยันรับเงิน/teacher/paymentsดูสลิป · ยืนยัน/ปฏิเสธการโอน

4.2 วันนี้ + ปฏิทิน

กดอะไรผลในระบบ
เพิ่มสล็อต / เปิดสล็อตวัน-เวลานั้นว่างให้นักเรียนจองได้
ปิดสล็อต / ปิดช่วงวันไม่ให้จองช่วงนั้น (ถ้ามีนัดอยู่ต้องยืนยันก่อน)
จองให้นักเรียนสร้างนัดแทนนักเรียน · แจ้งนักเรียน · sync ปฏิทิน
เลื่อนนัดโดยครูย้ายสล็อต · แจ้งนักเรียน · sync ปฏิทิน
ยกเลิกนัดสล็อตว่าง · แจ้งนักเรียน · ไม่หักชั่วโมง
ทวงถามส่งแจ้งเตือนให้นักเรียนไปยืนยันนัด
บันทึกคลาส (มาเรียน)สถานะ done · รอลงชื่อจากนักเรียน · สร้างการบ้านถ้ามีโน้ต
ไม่มาเรียน (No-show)หักชั่วโมงทันที · แจ้งนักเรียน
ดูลายเซ็น / ฟังเสียงการบ้านเปิดไฟล์ที่นักเรียนส่งไว้

4.3 คำขอเลื่อนนัด

กดอะไรผลในระบบ
อนุมัติสล็อตเดิมว่าง · สล็อตใหม่ถูกจอง · นัดเป็นยืนยันแล้ว · แจ้งนักเรียน · sync Calendar
ปฏิเสธนัดกลับไปใช้เวลาเดิม · แจ้งนักเรียน

4.4 ยืนยันรับเงิน (สำคัญมาก)

กดอะไรผลในระบบ
ดูสลิปเปิดรูปสลิปที่นักเรียนอัปโหลด
ยืนยันออเดอร์สำเร็จ · เติมชั่วโมง (งวดสุดท้าย) · แจ้งนักเรียน
ปฏิเสธออเดอร์ยกเลิก · แจ้งนักเรียน · ไม่เติมชั่วโมง

หมายเหตุ: ถ้าเป็นลิงก์ผ่อนหลายงวด — งวดกลางยืนยันแล้วอาจยังไม่เติมชั่วโมงจนกว่างวดสุดท้าย

4.5 นักเรียน / ลิงก์ชำระ / วอเชอร์ / ผู้ใช้

กดอะไรผลในระบบ
เพิ่มคอร์ส / ให้ชั่วโมงทันทีเติมชั่วโมงให้นักเรียนทันที (ไม่ต้องโอน)
สร้าง offer รอชำระนักเรียนเห็นรายการรอชำระในหน้าแพ็กเกจ
สร้างลิงก์ชำระเงิน/ผ่อนได้ลิงก์ส่งนักเรียน · เมื่อโอนแล้วเข้าคิวตรวจสลิป
สร้างวอเชอร์นักเรียนใส่โค้ดตอนซื้อแพ็กเกจได้
ระงับผู้ใช้บัญชีนั้นเข้าสู่ระบบไม่ได้

4.6 ตั้งค่า + Google Calendar + LINE

กดอะไรผลในระบบ
บันทึกช่องทางรับเงินอัปเดต PromptPay / บัญชีธนาคารที่หน้าชำระเงิน
เพิ่ม/แก้แพ็กเกจขายอัปเดตแพ็กเกจบนหน้า Landing และหน้าซื้อ
เชื่อมต่อ Google Calendar (ครู)นัดเรียน sync เข้าปฏิทินครูอัตโนมัติ
Publish Rich Menuอัปเดตเมนู LINE OA

5) การหักชั่วโมงและแจ้งเตือนอัตโนมัติ

5.1 เมื่อไหร่หักชั่วโมง?

จังหวะหักหรือไม่
จอง / ยืนยันมาเรียน / ยกเลิก / เลื่อนไม่หัก
ครูบันทึกคลาส “มาเรียน”ยังไม่หัก — รอนักเรียนลงชื่อ
นักเรียนลงลายเซ็นหลังเรียนหัก
ครูบันทึก No-showหักทันที

5.2 งานอัตโนมัติของระบบ (ทุก ~5 นาที)

งานผล
เตือนก่อนเรียน ~1 วันแจ้งนักเรียนในแอป + LINE Flex · แจ้งครูที่กระดิ่ง
หมดเวลายืนยันนัดยกเลิกนัดอัตโนมัติ · สล็อตว่าง · แจ้งทั้งสองฝ่าย
ชั่วโมงใกล้หมด (≤2 ชม.)แจ้งนักเรียน
แพ็กเกจใกล้หมดอายุ (≤7 วัน)แจ้งนักเรียน

5.3 กระดิ่งแจ้งเตือน

  • โหลดรายการใหม่เป็นระยะ · มีตัวเลขจำนวนที่ยังไม่อ่าน
  • เปิดกระดิ่งแล้วถือว่าอ่านทั้งหมด
  • คลิกรายการแล้วพาไปหน้าที่เกี่ยวข้อง (เช่น สลิป, นัด, การบ้าน)
  • ถ้าผูก LINE แล้ว ข้อความสำคัญมักถูกส่งเข้า LINE OA ด้วย
