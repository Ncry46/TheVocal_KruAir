# Design: Student lesson history page

Date: 2026-09-08  
Status: approved (user: จัดมาเลย)

## Goal
Replace dense history table with a responsive list that works on phone and desktop — clear hierarchy, real totals, readable teacher notes.

## UI
- Header: title + stats (class count, hours used)
- List rows: date/time, lesson, hours badge, outcome tone
- Expandable-feel body: note + sample audio link
- Empty state

## Non-goals
- API changes, search/filter, PDF export
