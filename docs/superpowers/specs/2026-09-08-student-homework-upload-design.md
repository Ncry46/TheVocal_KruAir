# Design: Student homework page (upload + drag-drop)

Date: 2026-09-08  
Status: approved (user: จัดเลย)

## Goal
Redesign student homework page for clarity on all screen sizes, with drag-and-drop audio upload, while keeping record/mic and signature flows.

## UI
- Page header (title + pending count)
- Homework cards: lesson, teacher note, sample audio link
- Upload zone: drag-drop + choose file + mic record; preview then submit
- Submitted state: open link
- Signature section: keep behavior, clearer layout

## Non-goals
- API/schema changes
- Non-audio file types
